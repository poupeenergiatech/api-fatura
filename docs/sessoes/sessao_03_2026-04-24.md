## Diferenças Críticas entre PDFBox e pdfplumber

Esta sessão revelou que os dois extratores produzem **textos brutos completamente diferentes**
para o mesmo PDF. Os padrões regex não podem ser compartilhados.

| Aspecto                   | pdfplumber (Python)                          | Apache PDFBox (Java)                    |
|---------------------------|----------------------------------------------|-----------------------------------------|
| REF + Valor + Vencimento  | Duas linhas (cabeçalho + dados juntos)       | Cada um em sua própria linha separada   |
| PIS / COFINS / ICMS       | Embutidos nas linhas de Consumo-TUSD/TE      | Bloco de tributos separado, linha única |
| COSIP + ICMS              | Na mesma linha                               | Cada um em linha própria                |
| Ordem das páginas         | Pág. 1 primeiro (cabeçalho embaralhado)      | Itens da fatura vêm antes da pág. 2    |
| Código de instalação      | Não extraído (embaralhado)                   | Extraído com sucesso: 608764            |

## Novas descobertas do layout PDFBox

- **Número de instalação** está em linha separada após "CÓDIGO DA INSTALAÇÃO" → `608764`
- **Histórico de 13 meses** aparece como linhas `ABR26  313  29` — apenas 5 meses com dados (NOV25 a ABR25 sem leitura nesta fatura)
- **PDFBox** produz texto mais "limpo" e estruturado que pdfplumber para esta fatura
- A ordem das seções no texto extraído é diferente da ordem visual da página
