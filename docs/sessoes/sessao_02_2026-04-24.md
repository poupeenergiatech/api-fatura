### Estrutura da Página 1

**Bloco de cabeçalho (embaralhado pelo PDF):**
A seção de identificação no topo da página 1 tem o texto extraído de forma não-linear
pelo pdfplumber, misturando colunas. O nome do cliente correto aparece **na página 2**.

**Linha de totais:**
```
REF:MÊS/ANO TOTAL A PAGAR R$ VENCIMENTO    ← cabeçalho (linha i)
04/2026 350,89 22/04/2026                   ← dados (linha i+1)
```

**Datas de leitura (tudo em uma única linha):**
```
DATAS DE LEITURAS LEITURA ANTERIOR 04/03/2026 LEITURA ATUAL 02/04/2026 N° DE DIAS 29 PRÓXIMA LEITURA 04/05/2026
```

**Itens da fatura (tributos embutidos nas linhas de consumo):**
```
Consumo-TUSD kWh 313,00 0,57337503 179,46 8,17 179,46 20,00 35,89 0,43260000 PIS 246,99 1,02 2,51
Consumo-TE  kWh 313,00 0,41305269 129,28 5,87 129,28 20,00 25,85 0,31164000 COFINS 246,99 4,67 11,53
Ilum. Púb. Municipal 34,94 ICMS 308,74 20,00 61,74   ← COSIP e ICMS na MESMA linha!
```
- PIS e COFINS: o valor final (3ª coluna) é o valor em R$
- ICMS: formato "ICMS base_calculo aliquota **valor_rs**" → pegar último número
- COSIP: número imediatamente após "Municipal"

**Tabela do medidor:**
```
2241341367 Energia Ativa Único 3.773,00 4.086,00 1,00000 313,00
```
Colunas: número_medidor, grandeza, posto, leit_anterior, leit_atual, constante, consumo_kwh

```

```
